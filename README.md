# เว็บไซต์ระบบบริหาร รพ.สต.ทรายมูล (SaiMun-PHC Management System)

ต.ทรายมูล อ.สว่างแดนดิน จ.สกลนคร — ธีมสี Transformative Teal ปุ่มและเมนูแบบสามมิติ

## เปิดใช้งาน
ดับเบิลคลิก `index.html` (ไม่ต้องติดตั้งโปรแกรมใด ๆ)

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้า (แถบเมนูด้านข้าง แถบค้นหา ปีงบประมาณ) |
| `assets/js/config.js` | **แก้ที่นี่** ชื่อหน่วยงาน ผอ. หมู่บ้าน เมนู 12 กลุ่มงาน ลิงก์ภายนอก และช่องข้อมูลของทุกทะเบียน |
| `assets/js/store.js` | ชั้นจัดการข้อมูล + ข้อมูลตัวอย่าง |
| `assets/js/app.js` | หน้าจอทั้งหมด (แดชบอร์ด กลุ่มงาน ทะเบียน ปฏิทิน ค้นหา ตั้งค่า สำรองข้อมูล) |
| `assets/css/style.css` | ธีมสี Transformative Teal / ปุ่มสามมิติ / รองรับมือถือ |
| `assets/img/logo.png` | ตราสัญลักษณ์ รพ.สต.ทรายมูล (เปลี่ยนได้ โดยวางไฟล์ใหม่ทับชื่อเดิม) |

## เรื่องข้อมูล (สำคัญ)
- ตอนนี้ข้อมูล**เก็บในเบราว์เซอร์ของเครื่องที่เปิดใช้เท่านั้น** (localStorage) ไม่ได้เชื่อมต่อฐานข้อมูลของเว็บต้นแบบหรือฐานข้อมูลใด ๆ
- แต่ละเครื่อง/เบราว์เซอร์มีข้อมูลแยกกัน — ใช้เมนู “สำรอง / กู้คืนข้อมูล” เพื่อดาวน์โหลดหรือย้ายข้อมูล
- ก่อนใช้งานจริง: เมนู “สำรอง / กู้คืนข้อมูล” → “ล้างข้อมูลทั้งหมด” เพื่อลบข้อมูลตัวอย่าง
- หากต้องการให้ทุกเครื่องใช้ข้อมูลร่วมกัน ให้เปลี่ยนเฉพาะฟังก์ชันใน `Store` (store.js) ให้เรียก API ของ รพ.สต. เอง เช่น Google Apps Script + Google Sheets — หน้าจอไม่ต้องแก้
