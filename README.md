# เว็บไซต์ระบบบริหาร รพ.สต.ทรายมูล (SaiMun-PHC Management System)

ต.ทรายมูล อ.สว่างแดนดิน จ.สกลนคร (สังกัด อบจ.สกลนคร) — ธีมสี Transformative Teal ปุ่มและเมนูแบบสามมิติ

- เว็บไซต์: https://sayemoon-1p.github.io/SaiMun-PHC-Management-System/
- ฐานข้อมูลกลาง: Firebase โปรเจกต์ `saimun-phc` (Cloud Firestore, ภูมิภาค asia-southeast1 สิงคโปร์)
  — คอนโซล https://console.firebase.google.com/project/saimun-phc/overview

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้า (แถบเมนูด้านข้าง แถบค้นหา ปีงบประมาณ) |
| `assets/js/config.js` | **แก้ที่นี่** ชื่อหน่วยงาน ผอ. หมู่บ้าน เมนู 12 กลุ่มงาน ลิงก์ภายนอก และช่องข้อมูลของทุกทะเบียน |
| `assets/js/firebase-config.js` | ค่าการเชื่อมต่อ Firebase (เปิดเผยได้ ไม่ใช่รหัสลับ) และ UID ของผู้ดูแลระบบหลัก |
| `assets/js/cloud.js` | เชื่อมต่อ Firebase: เข้าสู่ระบบ, ซิงก์ข้อมูลแบบเรียลไทม์, ออกเลขหนังสือไม่ซ้ำ, จัดการผู้ใช้ |
| `assets/js/store.js` | โหมดสำรอง: เก็บข้อมูลในเบราว์เซอร์ (ใช้เมื่อ apiKey ใน firebase-config.js ว่าง) |
| `assets/js/app.js` | หน้าจอทั้งหมด (เข้าสู่ระบบ แดชบอร์ด กลุ่มงาน ทะเบียน ปฏิทิน ค้นหา ผู้ใช้งาน ตั้งค่า สำรองข้อมูล) |
| `assets/css/style.css` | ธีมสี / ปุ่มสามมิติ / รองรับมือถือ |
| `assets/img/logo.png` | ตราสัญลักษณ์ รพ.สต.ทรายมูล |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล (สร้างจาก `tools/build-rules.js`) |

## ความปลอดภัยของข้อมูล
- ต้องเข้าสู่ระบบด้วย **ชื่อผู้ใช้ + รหัสผ่าน** ก่อนเห็นข้อมูลใด ๆ
- อ่าน/เขียนข้อมูลได้เฉพาะบัญชีที่ **ผู้ดูแลระบบเพิ่มไว้** และยังเปิดใช้งาน — บังคับที่ Firestore Security Rules (ฝั่งเซิร์ฟเวอร์)
  ไม่ใช่แค่ซ่อนปุ่มบนหน้าเว็บ บัญชีที่ไม่ได้รับอนุญาตจะถูกปฏิเสธ (HTTP 403)
- บัญชีใหม่ได้รหัสผ่านชั่วคราว และต้องตั้งรหัสผ่านใหม่ของตัวเองเมื่อเข้าระบบครั้งแรก

## งานของผู้ดูแลระบบ
- **เพิ่มเจ้าหน้าที่:** เมนู “ผู้ใช้งานระบบ” → “เพิ่มผู้ใช้งาน” → แจ้งชื่อผู้ใช้ + รหัสผ่านชั่วคราวให้เจ้าหน้าที่
- **เจ้าหน้าที่ลืมรหัสผ่าน:** ระงับบัญชีเดิม แล้วสร้างบัญชีใหม่ (Firebase แบบฟรีไม่ให้ตั้งรหัสผ่านแทนผู้อื่น)
- **สำรองข้อมูล:** เมนู “สำรอง / กู้คืนข้อมูล” → ดาวน์โหลดไฟล์ .json (แนะนำทุกสิ้นเดือน)

## เมื่อเพิ่ม/ลบทะเบียนใน config.js
ต้องปรับกฎความปลอดภัยให้รู้จักทะเบียนใหม่ด้วย (ไม่อย่างนั้นทะเบียนใหม่จะบันทึกไม่ได้):
```
node tools/build-rules.js
firebase deploy --only firestore:rules --project saimun-phc
```

## โควตาฟรีของ Firebase (Spark)
อ่านข้อมูล 50,000 ครั้ง/วัน, เขียน 20,000 ครั้ง/วัน, พื้นที่ 1 GB — เพียงพอสำหรับ รพ.สต.
ระบบโหลดเฉพาะทะเบียนที่เปิดดูอยู่ เพื่อประหยัดโควตา
